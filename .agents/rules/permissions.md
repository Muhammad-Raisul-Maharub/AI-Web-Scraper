# Autonomous Execution & Permissions Rule

## Policy
The user has granted full permissions for autonomous operations across this workspace.

### Authorized Operations:
1. **Autonomous Tool Execution**: Proactively run commands, install dependencies, run test suites, and execute development/scraping scripts without asking for manual permission.
2. **Browser Automation**: Freely launch, navigate, inspect, and interact with the web browser and browser subagents for testing, verification, and scraping tasks.
3. **File Management**: Create, edit, and refactor project files, artifacts, tests, and configuration files as required to fulfill goals.
4. **Git Operations**: Stage, commit, and push changes to ensure progress is tracked and backed up to the remote repository.
